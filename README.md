## Project title: Wells Fargo Software Engineering Job Simulation on Forage

### Context: Built as a part of the Wells Fargo Software Engineering Job Simulation on Forage

### **Status:** Complete

### **Project Description:**
- Developed an entity relationship diagram (ERD) suitable for financial advisors based on given requirements regarding client portfolios and system functions. 
- Utilised Spring framework in Java to implement a data model built previously through entity relationship diagram (ERD). 
- Mapped all planned entities into Java classes using Java Persistence API (JPA). 

### **Technology Stack:**
- Java
- JPA
- Spring Framework
